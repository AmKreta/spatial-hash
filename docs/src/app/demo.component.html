Both simulations use straight-line motion (y = mx + c) with randomized dx and dy of ±1 after a wall or particle collision. A line connects each pair of particles whose centers are less than 100 pixels apart. The brute-force and SpatialHash canvases each run in a dedicated Web Worker with their own OffscreenCanvas.

What to watch: at {{ particleCount() }} particles, brute force considers up to n(n − 1) / 2 pairs each frame. SpatialHash narrows each particle's candidates to a local 100-pixel neighborhood. Both workers yield between batches so the controls stay responsive at high counts.
