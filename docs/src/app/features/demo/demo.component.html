THE GRID IN MOTION

Same particles. Smarter shortlist.

Two identical worlds. One scans every particle; the other checks only target-cell candidates with SpatialHash.

Watch the target lookup as the particle count grows.

Particles move in straight lines and bounce off the walls. Entering the dotted center target turns a particle bright yellow; particles outside stay muted. Each canvas runs in its own Web Worker with a dedicated OffscreenCanvas. Processing time includes the full brute-force scan or the SpatialHash refresh plus its target query; cooperative yield waits are excluded.

↗

What to watch: brute force checks all n particle positions. SpatialHash checks only k candidates from cells around the target. The scan is O(n); the indexed query is O(k) after an O(n) refresh for the moving particles.
