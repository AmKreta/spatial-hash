Same particles. Smarter shortlist.

Two identical worlds. One scans every particle; the other checks only target-cell candidates with SpatialHash.

Watch the target lookup as the particle count grows.

Particles move in straight lines and bounce off the walls. Entering the dotted center target brightens a particle's existing color; particles outside stay muted. Each canvas runs in its own Web Worker with a dedicated OffscreenCanvas. The SpatialHash index persists between frames and updates membership only when a particle crosses a cell boundary. Processing time includes movement plus the full scan or index maintenance and target query; drawing and yield waits are excluded. Cards and charts show the same 10-frame averages.

What this demonstrates: find all particles inside the center target viewport. Brute force checks all n positions; SpatialHash checks candidates in nearby cells.

How to compare: raise the particle count, compare positions checked, then read the 10-frame processing-time average. That timing includes index upkeep, so one target lookup can still favor a direct scan.
